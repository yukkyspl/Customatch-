# CusToMatch — 車カスタムシミュレーター

好きな車種に、実在するパーツを組み合わせてリアルタイムでカスタム体験できるWebアプリです。

## 特徴

- 国産・外車・マイナー車まで幅広い車種に対応
- ホイール・エアロ・リアウイング・内装・エンジンルームのパーツを自由に組み合わせ
- 各車種の純正カラーを正確に再現
- 前後左右＋エンジンルーム＋室内の6アングルでプレビュー
- Amazon・Yahoo!・楽天でそのまま注文可能
- ユーザー投稿で車種・パーツデータが増えていく仕組み

## 使い方

1. 車種を選ぶ（メーカー→車種→型式）
2. ボディカラー・パーツを選ぶ
3. 気に入ったらSNSでシェア or そのまま注文

## 技術

HTML / CSS / JavaScript（ワンファイル構成）
